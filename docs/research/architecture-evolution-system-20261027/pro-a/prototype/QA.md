## 1. 数据与差异规则

模型测试涵盖三个项目共用合同；Mica 共享信号原本存在而普通输入关系被撤销；布局和顺序变化不制造架构变化；删除边后仍能找到旧消费者；有环时有限结束；缺少实现锚点和未知状态被拒绝；没有传递对象、缺少变更原因或范围错误被拒绝；局部历史的上下文不能悄悄改变。

另外核对：旧理由不能覆盖或删除；同名锚点不能重新指向其他提交；旧证据与快照不能被新记录替换；可变分支链接不能冒充固定提交；源码和测试定义不能成为运行通过；文本片段重定位遇到重复或改名保持歧义／未解析。

这些是针对具体失真风险的正反例，不是把实现函数逐行复制到测试。结构化字段比较仍可能把正文改写视作变化，是否值得形成修订由设计者决定。

## 4. 首轮问题与实际修复

| 首轮问题 | 修复 | 复验依据 |
| --- | --- | --- |
| Graphviz 把 ID 连字符编码为实体，语义属性注入未命中 | 规范化受控 ID；构建时断言所有节点和边成功映射 | 实际图形操作与节点数量检查 |
| 边路径在嵌套 SVG 组内，直接子元素 CSS 未命中 | 改为后代路径选择，增加透明宽命中线 | 鼠标选择及真实计算样式 |
| 手机图中文字过小 | 默认改用完整组件／关系列表，可选内层横向图 | 字号、点击、滚动、无页面溢出 |
| 局部历史被计为全图“不变” | 使用 `context` 范围，排除未核实历史的计数 | Mica 和 CAT 模型反例及实际文字 |
| 比较旧边或旧同端点边可能取到新来源 | 选择保留端点；非比较模式优先所选修订 | DA 两类历史关系实际操作 |
| 手机关系选择后未自动进入详情 | 与组件下钻共用滚动与返回 | 详情和概览位置断言 |

Graphviz 与 Chromium 的 SVG 组即使 `display:none`，本环境 Playwright 仍可能返回非零边界框。因此旧边隐藏使用计算样式及实际截图判断，不把 `isVisible()` 的该次误判当作产品缺陷，也没有删掉隐藏检查来获得通过。

## 5. 环境与可复现限制

实际使用 Chromium **131.0.6778.204**、Playwright **1.62.1**、Node **v24.22.1**。Chromium 只访问本地研究原型，没有复用用户登录会话，没有打开源码外链。默认运行环境没有可用浏览器与中文字体，本轮从官方来源取得隔离浏览器和 Noto 字体供本地渲染；这些二进制、字体和缓存没有进入提交。

优先尝试的云浏览器不能访问本地服务器；默认 Playwright 浏览器下载端点也没有返回可用归档，因此采用官方 Chrome for Testing 的明确版本完成本地核验。这一测试版本不被写成当前最新浏览器。初次 R2 浏览器阅读只用于理解前轮材料，不替代或重写原 A/B 分数。

`npm test` 直接运行 Node 原生测试文件。本环境的 `node --test` 子进程汇总只显示文件级结果，因此最终记录采用能够逐项显示 13 个断言的直接运行结果。
