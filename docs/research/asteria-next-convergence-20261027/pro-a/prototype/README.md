# Asteria Next reference prototype

直接打开 [preview.html](preview.html)。它是自包含的只读候选，包含四个项目、字体、代码高亮和公式资源；阅读与切换主题不依赖网络。打开具体来源链接时，仍按原仓库权限访问。

原型使用同一份语义模型与页面应用。四个项目不是四套独立网站，历史修订也不是按预先涂色的对象列表假装计算。实际语义计算和其边界见 [model-core.js](src/model-core.js)，完整正式合同见上一级的 [SEMANTIC_MODEL.md](../SEMANTIC_MODEL.md)。

## 建议按这几条阅读任务检查

| 任务 | 入口和操作 | 应能看见什么 |
|---|---|---|
| 纯设计系统能否成立 | Delivery Assurance → 当前架构 → 正常交付 / 返修 / 恢复 / 保护已有能力 | 同一拓扑的路径，具体载荷与消费者；“实现”可以为空 |
| 软件机制能否追到真实源码 | Mica → 清空后旧草稿恢复 → 实现 | 实际文件、函数、selector、完整固定提交链接及源码节选 |
| 改变是否有真实原因 | Mica → 修订 → 0.1.6 → 0.1.7 的对照 | 机制前后内容、移除的输入关系、三对核过的函数、触发原因和保留行为 |
| 科研未知是否被保留 | CAT-TRACE → 匿名零槽位积分 → 机制 / 实现 / 证据 | 数学目标、候选路线、无生产例程的合法状态、反例与开放条件 |
| 被撤销路线是否还能追查 | CAT-TRACE → 修订 → 撤销匿名零槽位的普通局部近似 | 撤销依据、仍在研究的替代方案和保留对象 |
| 成品为什么未通过 | STAT5060 Tutorial → 具体问题 | 当前课程事实漂移、验收程序缺陷、历史局部修复分别归属 |
| 修复后哪些证据需要重做 | Tutorial 的具体问题 → 变更影响预览 | 页面、样式、顺序、统计输入改变时，对应的复验和可保留范围 |
| 设计是否还缺关键行为 | 任一项目 → 检查 | 当前问题、实际结构检查与范围审阅；不产生自动冻结批准 |

右上角切换明暗主题。手机默认按路径和对象阅读，图按需展开；修订中的变化对象提供可读列表。来源窗口支持 Tab、Shift+Tab、Escape 和焦点返回；图节点及关系标签可用键盘操作。

## 本地重建

保留整个 `pro-a/` 目录，因为 Mica 的历史来源记录在 `../sources/` 中，也是构建输入。

```bash
cd prototype
npm ci
npm run build
npm test
```

本轮实际环境为 Node 24.22.1。`npm run build` 使用 ELK 生成位置与路由，使用 Shiki 生成代码双主题，随后 Vite 将应用和静态资源内联到 `preview.html`。原文件与锁文件已保存，不需要账号、服务端或数据库。开发时可运行 `npm run dev`，默认在 `127.0.0.1:4173` 打开。

模型测试覆盖会产生错误结论的边界：空实现、失效引用、错误证据类型、历史与当前混用、缺失修订原因、关系改向、删除消费者以及证据依赖未知等。结果保存在 [model-tests.tap](../qa/model-tests.tap)，不把模型测试通过解释为产品获得最终验收。

## 文件组织

| 文件 | 职责 |
|---|---|
| `src/reference-data.js` | 四项目共同模型及有目的的阅读投影 |
| `src/source-evidence.js` | 固定研究来源、公开源码节选和可公开的科学/Artifact 概念 |
| `../sources/mica-historical-anchors.json` | 三对真正属于 0.1.6 / 0.1.7 的固定源码锚点 |
| `src/model-core.js` | 引用校验、语义差异、历史并集与证据依赖计算 |
| `scripts/prepare.mjs` | 构建期布局、边路由、代码高亮与派生产物 |
| `src/Graph.jsx` | 系统图、关系和选择行为 |
| `src/Details.jsx` | 机制、源码、公式、页面、finding、证据与修订表达 |
| `src/main.jsx` | 当前架构 / 修订 / 检查及响应式导航 |
| `src/style.css` | 布局、两套主题、状态、焦点与窄屏阅读规则 |
| `src/generated.js` | 可重建的几何及代码渲染结果，不是第二份事实源 |
| `src/assets/` | 随候选提供的字体及许可 |

`node_modules/` 和 `dist/` 不提交。最终自包含入口为 `preview.html`；仅打开源码 `index.html` 需要 Vite 开发服务器。

## 已演示与尚未实施的边界

原型实际计算引用检查、范围内的实体/关系/绑定差异、旧新关系并集和示例证据依赖。页面提供真实项目切换、节点/关系选择、来源、证据、历史、差异、finding、主题与手机阅读。

它没有实现正式 Asteria 的通用导入、无损迁移、编辑/提交、Tree-sitter / SCIP 自动索引、长期来源监测、不可变冻结记录或真实批量 Artifact 解析。这些有明确规格和阶段合同；没有用固定研究数据冒充已完成的生产功能。历史对照由来源重建，未收集的旧绑定保持未覆盖，不计成新增。

CAT-TRACE 和 Tutorial 的私有源码、数值数据、完整报告与原始页图不复制进此原型。固定来源链接保留访问边界，页面列表表达对象结构；它们不是伪造的原始截图。此原型也不会执行源项目的验收或修复。

实际 Chromium 检查、最终截图、可见正文审查及遗留范围见 [CONTENT_AND_TASTE_AUDIT.md](../CONTENT_AND_TASTE_AUDIT.md)。第三方组件及字体的使用见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
