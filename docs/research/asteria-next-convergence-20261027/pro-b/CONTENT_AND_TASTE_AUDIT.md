# 内容存在性与整页品味审查

## 1. 审查方法

对四个项目的默认系统页、组件、关系、机制、实现、证据、演进、差异、完整性检查、light／dark 和 mobile 真实渲染逐项执行 KEEP／DELETE／MERGE／RELOCATE／REWRITE。审查对象是最终可见页面，不以静态源码字符串替代。结果只保存在本文件和 `prototype/qa/visible-content-audit.json`，不进入产品 UI。

## 2. 全局裁决

| 元素 | 决定 | 处理 |
|---|---|---|
| 项目长摘要 | KEEP／REWRITE | 首页保留一段，手机限制可见行数；不在系统图旁重复。 |
| 当前 revision | KEEP | 只在标题区主要位置显示一次；演进页展开。 |
| 全部 schema 字段 | DELETE | 只在用户选择对象、且对当前任务有信息增量时显示。 |
| 路径说明 | KEEP／RELOCATE | 桌面在路径栏，手机在路径标题下；不进入每个节点。 |
| 节点状态 badge | MERGE | 改为边线、线型和一行 meta；不在每个区域重复 badge。 |
| 图与正文重复 | DELETE | 图已表达拓扑，正文只解释真实责任、机制和边界。 |
| source path／commit | RELOCATE | 只在实现页签；系统图不显示。 |
| 证据计划 | REWRITE | 明确为计划／pending，不使用“已验证”措辞。 |
| 巨型全局时间线 | DELETE | 当前优先；局部历史和 meaningful revisions 按需。 |
| 内部编号 | RELOCATE | 只在 source／revision 的高级详情或 machine record。 |
| 开放与阻塞 | KEEP | 只在真正影响当前判断的位置，说明影响和退出条件。 |
| 图层控制 | KEEP | 桌面下沉到路径栏；手机删除，避免入口过多。 |
| 搜索 | KEEP | 顶部轻量入口，覆盖节点、关系、机制、源码与修订。 |
| 空卡片和占位标题 | DELETE | 没有实现／证据时用一句事实文本，不制造卡片。 |
| 研究过程与角色分工 | DELETE | 不进入产品；只保留承担者、证据生产者等必要事实。 |
| 状态 reassurance | DELETE | 不重复“安全、完整、已保护”等口号；只显示证据。 |

## 3. 分状态审查

### 默认系统

保留项目摘要、四个主视图、路径、拓扑和空 inspector 提示。删除全局指标、修订时间线、所有检查状态和开源工具说明。第一眼能识别系统结构，且不要求用户先读报告。

### component／relation

组件详情只显示当前责任、机制入口和按页签下沉的实现／证据／历史。关系详情只显示生产者、载荷、消费者和必要失败语义。删除重复状态、来源列表和无关 metadata。

### mechanism

保留承担者、输入、输出、关键步骤和参与对象。实现锚点只列真正存在的绑定；design-only 使用一句合法为空说明。删除“机制是什么”的报告式定义和所有项目同句式卡片。

### implementation／evidence

实现只显示 path、symbol、commit 和必要状态；证据显示观察与限制。删除原始索引日志、哈希列表、全部测试输出和“文件存在即通过”的暗示。

### evolution／diff

保留 before／after、原因、触发证据、影响、不变保证和 alignment。删除每个 Git commit、保存动作和纯视觉坐标变化。变化 token 下沉为证据，不抢占正文。

### validation

保留具体结构检查和专业判断边界。删除总分、百分比、绿色大卡和“因此架构正确”的结论。

### mobile

重排为路径顺序阅读和底部详情。删除桌面图、图层控制、复制视图按钮、帮助入口和完整长摘要。底部导航只保留四个主视图与项目切换。

## 4. 人话审查

已删除或重写：报告式自我定义、反复“不是 X 而是 Y”、先否定用户未问内容、内部工程状态口号、所有组件相同句式、无价值 reassurance、执行角色故事和冗长并列。必要的产品边界在规格文档中完整保留，产品 UI 只呈现当前阅读所需事实。

去掉 CSS 后，HTML 的顺序仍为：品牌和项目 → 项目标题与摘要 → 主视图 → 当前结构／机制／修订／检查 → 对象详情。没有依赖装饰图形才能理解的营销语句。

## 5. 第一轮整页结论

桌面 light／dark 与手机 light／dark 均完成真实浏览器截图；主要页面没有无意义渐变、巨大状态卡、到处 pill、装饰几何、过量边框或密集 dashboard 指标。初次截图发现手机关系载荷继承默认按钮边框，已在正式截图前修复。最终 P1 = 0，明显 P2 = 0；这只是 producer QA 结论，不代替下一轮 GPT Work 或最终裁决。
