# Delivery Assurance 架构原型

这是第二轮设计研究的交互式静态原型，不是 Delivery Assurance 的实现，也不发布正式网站。

## 查看

直接打开 `index.html` 可以浏览；为避免浏览器对本地脚本的限制，也可在本目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 交互

- 切换“正常交付”“验收失败，返回原任务”“新修复破坏旧功能”，同一架构图会突出对应路径。
- 点击节点，查看存在理由、输入、输出、接收者、缺失后果和当前状态。
- 点击连线，查看传递内容、触发条件、实际接收者、怎样算接通以及当前接线缺口。
- 手机宽度下，宽图会改排为顺序路径和组件索引，不把桌面图整体缩小。
- 所有节点和连线均可通过键盘聚焦；Enter 或空格打开详情。

## 文件

- `index.html`：页面结构和所有静态正文。
- `architecture-data.js`：组件、连接、情境与动态中文文案的唯一数据源。
- `app.js`：节点、连线、情境和手机视图交互。
- `styles.css`：视觉系统、响应式布局和交互状态。
- `verify.py`：本地浏览器检查与截图脚本。
- `export-copy-audit.py`：从页面与架构模型重新生成逐句审校清单。
- `export-architecture-model.py`：从同一数据源生成完整架构文档。
- `export-manifests.py`：生成源码与截图哈希清单。
