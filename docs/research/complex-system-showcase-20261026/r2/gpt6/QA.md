## 实际观察

- 1440×1000 首屏完整主图底边约在 802px；额外复看 1366×768，主图底边在 764px，全部节点与连接仍在首屏。
- 14 个组件逐个点击，详情对应；高亮集合与模型的真实相邻连接一致。16 条连接逐条点击，能读到载荷、消费者和实现状态。
- 正常 5 步、错误 7 步、旧功能回归 7 步均逐步前进和后退；首尾按钮边界正确，路径集合与文字同步。情境步骤更新右侧相关组件详情，避免保留上次选中的无关内容。
- 在 320、360、390、768、1024、1280、1440 CSS 像素宽度检查，无页面横向溢出。手机采用独立纵向布局；所有节点、边和 19 步重新实际操作。
- 双端节点文字边界、连接标签与节点重叠检查通过。手机长图上、中、下三段另外以正常大小实际复看，所有主要名称、连接标注和按需能力可读。
- Enter/Space 选择、Escape 关闭、手机详情 Tab 焦点约束与关闭后返回原对象实际有效。减少动态效果偏好受尊重；没有自动播放动画。
- 禁用 JavaScript 后完整图、正文和依据仍在，提示交互限制。没有浏览器脚本错误。
- 272 个可见文本 ID 与审校源一致，含动态详情、情境、手机和无脚本提示。逐条人工编辑与连续阅读另见 COPY_REVIEW；数量和一致性不是语言质量评分。

## 发现并修正的问题

| 实际问题 | 处理与复查 |
| --- | --- |
| 请求与续修共用末段路径，点请求误选续修 | 续修改走 Codex 底部独立入口，实际点击再次通过 |
| 某些较宽连线命中区盖住其它连接标签 | SVG 路径与可聚焦标签分层，双端逐条点击全部通过 |
| 手机交付线穿过 Bridge 节点 | 改走右侧外缘，真实长图复看 |
| 手机运行检查标签贴入成品节点 | 标签向外移，新增全部标签不覆盖节点的检查 |
| 手机步骤说明离按钮过远、默认无效控件挤占图 | 说明随情境置于图前；默认省去无效步骤控件和重复读图文字 |
| 切换情境后右栏保留上次连接详情 | 右栏随当前步骤更新相关组件；选择组件时恢复关系观察 |
| 两个依据折叠项的来源链接对调 | 按正文对象重接历史源码与当前架构来源 |
| 重复品牌、内部行话、手机单字断行 | 按逐句记录修改，重提取文字、重拍全部最终截图 |

初稿截图只留在工作过程，不纳入交付；`previews/` 的 11 张图均来自最终源码。`complete-website.png` 是将四个依据项展开后的完整页面；其它截图名称明确对应默认、组件、连接、失败、返修、回归和手机状态。
