# Delivery Assurance 高保真静态原型

这是复杂系统展示模板的第一份完整视觉样例。它只用于设计评审，不是 Delivery Assurance 的生产实现，也不证明任何宿主接线或自动验收已经存在。

## 直接查看

在本目录启动任意静态服务器：

```bash
python3 -m http.server 4173
```

随后打开 `http://127.0.0.1:4173/`。

无需安装依赖。`index.html` 保留完整基础内容；`prototype.js` 只增强三个结果场景和组件合同切换。禁用 JavaScript 时，读者仍能看到默认完整路径、证据账本和推荐结论。

## 有意义的交互

- “正常完成 / 发现失败 / 旧功能保护”切换同一任务的三种结果，而不是播放装饰动画。
- 五阶段任务链允许逐步查看输入、动作、消费者和证伪条件。
- 组件检查器回答“为什么存在、交给谁、删除后失去什么”，并显示真实完成状态。
- 证据账本使用原生 `details`，区分历史事实、源码存在、已审设计和未验证能力。

## 桌面与移动评审

- `index.html`：完整桌面原型；缩放浏览器即可检查全部响应式断点。
- `mobile-preview.html`：固定 390 × 844 视窗，直接检查移动端阅读与交互。
- `review/README.md`：实际渲染、交互、溢出和控制台检查记录。

本轮曾在 Chromium 中生成桌面与移动全页截图用于视觉复核；正式可审阅成果保留为可操作 HTML，避免压缩截图掩盖文字和交互。
