# 视觉原型评审入口

桌面原型：[`../index.html`](../index.html)  
固定移动预览：[`../mobile-preview.html`](../mobile-preview.html)

评审尺寸：

- 桌面：1440 × 1100，并检查 1440 × 4811 全页。
- 移动：390 × 844，并检查 390 × 7191 全页。

检查结果：

- 首屏不依赖流程图即可说明产品价值与真实完成边界。
- 三种场景、五阶段机制和组件合同均可操作。
- 组件状态没有把“拟建”“合同已有”“源码存在”写成“已上线”。
- 移动端没有整页横向溢出；组件选择器只做局部横向滚动。
- 键盘焦点可见，按钮触控高度至少约 42–46 像素，支持减少动态效果。
- 页面不使用无信息价值的插图、巨大装饰、节点画布、拖拽、缩放或自动播放。
- 桌面与移动浏览器控制台均无脚本错误。

本轮实际渲染截图用于视觉检查；提交保留可操作 HTML 原型，避免压缩图损失文字与交互。
