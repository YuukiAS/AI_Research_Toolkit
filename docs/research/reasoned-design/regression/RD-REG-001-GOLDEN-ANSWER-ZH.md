从头来一次，直接给你最终能用的答案。

**结论：我建议你在 Mac mini 上装 RClick。**

如果你的要求严格是“只补 Windows 那种右键 → 新建文件，其他什么都不要”，第二选择是 **New File Menu Lite**。但如果既然要装一个 Finder 扩展，希望顺便把复制路径、指定应用打开、快速目录、隐藏文件这些 macOS Finder 本来就缺的右键能力一起补上，**RClick 是我现在认为最合理的默认选择**。

所以这里其实有三个不同的问题，答案不要混在一起：

- **免费方案里综合最值得装：RClick**
- **只想补“右键 → 新建”：New File Menu Lite**
- **想把 Finder 右键做成一个大型文件工具箱：FileMint / iRight 这一类再比较**

你现在属于第一种。因为你最开始是被“不能右键新建”触发，但既然真要在新 Mac mini 上长期留一个 Finder 扩展，复制路径、指定应用打开、快速目录这些对你也不是无用功能。RClick 的功能范围还没有膨胀到 OCR、视频转 GIF、图片转换这种程度，我认为边界更合理。

### 为什么最后是 RClick

第一，它不是我从官网功能列表里随便挑出来的。

它 2024 年已经有独立 V2EX 发布讨论，当时定位就是 Finder 右键增强：新建文件、复制路径、指定应用打开、直接删除。到现在 GitHub 已经约 **1.1k Star、91 Fork**，而且仍然是活跃项目。

第二，它的功能刚好跨过“值得装一个扩展”的门槛。

除了你现在要的：

**右键 → 新建 TXT / Markdown / JSON / Word / Excel / PPT / Pages 等**

它还能：

**复制完整路径、用指定应用打开、固定常用目录、隐藏/显示文件、AirDrop。**

这些是 Finder 文件操作本身的增强，不是在右键菜单里硬塞一个图片编辑器、OCR 工具箱。

第三，它有明确代价，我也不会藏起来。

RClick 要启用 Finder 扩展；涉及文件操作时会要求对应目录权限；某些自动化功能还需要辅助功能权限。当前仓库也还有 15 个未关闭 Issue，所以它不是“装上绝对零问题”。

但和几个 2026 年刚出现、几十到一百多 Star 的新项目相比，我更愿意把一个长期装在 Finder 里的扩展交给 RClick。

这批 V2EX 讨论已经很密集，所以这次正确的研究顺序应该是：**先吃透 V2EX 这一整片高相关讨论，再用 Reddit 做独立交叉验证，最后用 GitHub/App Store 核实项目事实。**而不是漏着这些帖子，到全网找一些零散软件介绍。

Reddit 的结果也提供了两个有用的独立信号：一方面，New File Menu Lite 确实有用户表示已经用了很多年，且 2026 年仍有人安装后确认行为接近 Windows；另一方面，2026 年仍有人不断新做 MacNewFile 这类工具，说明这个需求没有一个全社区统一的“标准答案”。

### 最后你现在怎么做

我会在 **Mac mini 安装 RClick**。

官方 GitHub 当前说明要求 macOS 15.6+，安装最新 Release 的 `.dmg` 后拖到 Applications，再启用 Finder Extension。

RClick 官方 Releases：  
https://github.com/wflixu/RClick/releases

装好以后，第一阶段只打开你真正会用的几项：

**新建文件、复制路径、用指定应用打开。**

快速目录你觉得有用再开；“直接删除、不进废纸篓”这种我反而建议先关着。

如果你装完发现自己明确觉得“这些额外东西我一个都不需要，我就要 Windows 那个新建菜单”，那就卸掉 RClick，换 **New File Menu Lite**。它从 2015 年做到现在，免费版 3 个模板对单纯 TXT / Markdown / 一个常用格式已经足够。

New File Menu Lite：  
https://apps.apple.com/us/app/new-file-menu-lite/id1066302071?mt=12

**所以我的默认动作不是“继续研究”：就是先装 RClick。**
