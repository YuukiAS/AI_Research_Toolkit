## 4. 如何判断某项真的被解决，而不是被分配了角色

每项必须保持五个层次独立：

1. 有可定位的原问题及来源；
2. 有明确的实际观察/修复入口和负责者；
3. 对原失败有因果针对性，缺证据不会成为PASS；
4. 正常入口中的实际坏行为能被发现、正常好行为可以完成；
5. 在新的日常任务中不反复退化，也不会因过重流程带来更大成本。

本轮246项完成的是前两层，并给出第三层的论证与缺口。仅A40–A42等局部观察有本轮隔离实测；第四、五层尚未在统一生产体系中验证。没有把分配K编号当作实现进展。
