## 4. 五种结论不能混为一谈

1. 有可定位原问题和来源；
2. 有明确的实际检查/修复入口与负责者；
3. 控制因果针对原失败，缺证据不会被解释为通过；
4. 普通入口中的真实坏行为被发现、正确行为可以完成；
5. 新日常任务中净减少回归、返修和人工负担。

当前已登记项具备前两层及第三层的具体设计论证；少数源代码观察有局部实测，第四、五层没有在统一生产体系中完成。v0.2给出完整系统形态、普通流程和六仓库变体，并未把分配模块名称当实现进展。
