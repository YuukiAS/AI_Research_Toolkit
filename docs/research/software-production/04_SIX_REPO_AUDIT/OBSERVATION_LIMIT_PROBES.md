# 已执行的局部反证：检查器到底看到了什么

日期：2026-10-13。性质：只读源码分析＋隔离临时目录实验。**不是研工台实现，不是六个产品的验收，也没有对产品仓库作任何改动。** 延续本目录 Asteria A40–A42 的观察，并补齐中断前未落盘的复现脚本和结果。

## 直接结果

从固定 Asteria 源码提取的 `routeGestalt` 无法观测其输出中的交叉数和浮动标签数；缺失或非有限的路由测量被当成零。原文件的科学内容保护使用无基准的 `git diff`，看不到暂存或已提交修改。**这使“把现有检查器冻结并强制运行即可防降级”的前提不成立：先要证明检查器确实能感知所声称的失败。**

来源：[Asteria 固定源码](https://github.com/YuukiAS/Asteria/blob/193c033659a7612a99442763077217b130e9b756/scripts/validate-architecture-rc19.mjs)，blob 为 `491531c6c21887033909d41e776d654c861a9e7e`。实际观察由 [脚本](probes/observation_limits.py) 产生，机器结果见 [JSON](probes/observation_limits.result.json)。

## 1. 对纯函数运行了什么

未导入 Vite，没有启动网站，没有调用 Asteria 的整个测试套件。仅逐字提取 `routeGestalt` 函数，在当前对话的隔离容器中用 Node v22.16.0 执行。

| 输入 | 提取函数与原文件对应数值条件的结果 | 这说明什么 |
|---|---|---|
| 有限短路径，比例1.1 | 满足条件 | 正常对照可以通过 |
| 有限长绕行，比例2.0 | 不满足条件，长绕行数为1 | 原检查并非所有项目都无效；已有长绕行检测有反应 |
| 完全没有路由比例 | 报告最大值/95分位为0，满足所提取条件 | 无测量被误当成理想测量，而不是不足以判断 |
| 路由比例为非有限值 | 过滤后又报告0，满足条件 | 无效输入也会消失成零 |
| 两条具有明确交叉的简单线段，附带标签矩形 | 两个报告计数仍为0 | 函数不读取几何和标签，不能据这两个字段证明无交叉、无浮动标签 |

最后一项仅是独立几何见证：由简单线段方向判定证实交叉，**不声称这些字段就是正式应用的最终SVG结构，也不证明真实浏览器回归会接纳该错误图**。源码自身把两个计数写为常量，已经足以界定其观察范围。相应浏览器套件还含其它真实几何和标签检查，不能据此否定整个项目的所有测试。

这里的 `listedConstraintsHold` 是复刻该函数附近所用数值条件的局部结果，**不是执行完整验证命令得到的总PASS**。

## 2. 对 Git 保护命令运行了什么

使用 Git 2.47.3，在脚本自己创建并最终清除的临时仓库里，建立一个测试文件的基线，然后修改、暂存、提交。禁止读用户Git配置或运行仓库钩子；没有接触真实Asteria工作树。

| 文件状态 | 原命令 `git diff --name-only -- <path>` | 明确检查对应范围 |
|---|---|---|
| 改动但未暂存 | 看到了文件 | 与工作区相对索引的含义一致 |
| 同样改动已暂存 | 空集合 | `git diff --cached` 仍看到文件 |
| 同样改动已提交 | 空集合 | 明确基线到候选的比较仍看到文件 |

因此，“工作区干净”不能证明“相对被批准的科学基线没有变化”。修复应使用已批准的基线和当前候选进行比较，再另外处理暂存和工作区变化；比较本身仍不能决定科学变化对不对。Git官方说明与实验一致：[git-diff](https://git-scm.com/docs/git-diff)，访问于2026-10-13。

## 3. 对组件选型的直接影响

Asteria需要先修原有观察器的证明范围和基线比较，不是新增一个更高层脚本去信任同样的零值。Mica已有的证据包验证器、Lucerna原生采集、SeminarArc视觉比较器和CUHK Date预检也必须分别回答“实际观测是什么”。不同权限保护解决篡改问题，无法让错误测量变正确；专业审查解决整体体验，也不能替代上述可计算判断。

拟议修改尚未实施。应在正常入口分别验证：正确对象能通过；实际破坏了相应行为的对象不能通过；缺测保持未验证；合法重构不因旧实现细节而被误拒绝。有限测试不能保证未来所有错误都能检出。

## 4. 复现与范围

在安装有Python 3.10+、Node和Git的非生产环境，从本目录执行 `python probes/observation_limits.py` 即可重新得到同结构结果。不安装依赖、不联网、不调用模型、无付费请求；只运行源码纯函数和临时Git实验。

保存结果中的三个字段均为false：`product_code_changed`、`real_gui_or_service_tested`、`production_system_implemented_or_validated`。本报告没有把局部反证成功冒充产品或生产框架已经通过验证。
