## 用户要的最终对象

不是仅供软件使用的一组规范，而是一套能够连续交付复杂产物的可执行生产体系：软件、网页、深度学习模型、统计/科研产物都适用；平台与领域检查可以不同。需要有可称呼的对象、实际运行形态、角色/进程、阶段输入输出、谁调用插件、谁运行验收、怎样恢复与终止、怎样维护规则。先为Lucerna创造价值，但不能把整个架构缩成Windows截图方案，也不能让Lucerna等到庞大中央系统建完。
