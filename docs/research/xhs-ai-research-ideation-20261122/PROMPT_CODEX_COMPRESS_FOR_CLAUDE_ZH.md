当前状态：原生小红书采集已经完成，远端分支中有 18 篇图文笔记、141 张截图和每篇 `note.md`。本轮不要再采集新帖子，也不要研究新的科研方案。你唯一任务是把现有原始材料一次性读完并整理成**分层、可追溯、低上下文成本**的文字证据包，让后续 Claude 默认不需要逐张读取 141 张图片；只有遇到关键歧义时，才按文件引用回看原图。

## 二、为什么这样整理

后续 Claude 的默认阅读对象必须是文字包，而不是 141 张图。目标是：

1. 一次性由 Codex 完成图片理解；
2. 保留原图作为最终证据；
3. 去掉重复 UI、装饰、标题复写和无关内容；
4. 把图片中真正新增的文字、流程、方法、失败经验和提示词结构转成可搜索文字；
5. 让 Claude 先读一个短索引，再按需要读完整证据包；
6. 若后续某个判断需要核对，能通过精确的帖子编号和图片编号回到原图。

这是一轮**证据压缩**，不是科研结论生成。

## 三、最终必须生成三层材料

### 第一层：每篇帖子的完整图片证据

在每个帖子目录新增：

`image_evidence.md`

它负责尽量完整地保存截图中相对于 `note.md` 新增的有效信息。

格式：

```markdown
# 图片证据

## 01.png

### 新增文字 / 信息
...

### 图示或结构
...

### 与 note.md 的关系
- 补充 / 重复 / 冲突 / 无新增信息

## 02.png
...
```

规则：

- 按图片原始顺序逐张处理，不能跳图。
- 如果截图主要是文字，保留会改变理解的关键原文；不需要机械抄小红书 UI、作者昵称重复、点赞按钮、页码、装饰词。
- 如果图片展示流程图、表格、比较、工具组合、提示词结构或方法步骤，必须把结构转成文字。
- 如果图片本身给出可复用 prompt、研究步骤或判断规则，尽量保留原句和顺序，不要只写一句摘要。
- 如果图片只是封面、重复正文或无新增信息，明确写“无新增信息”，不要为了填满文件编内容。
- 对看不清、被遮挡或只能部分确认的内容标记“无法确认”，不要猜。
- `note.md` 已经完整包含的正文不重复全文抄写，只记录图片新增部分。
- 不使用外部网页补齐帖子内容。

这一层可以相对详细，后续 Claude 默认不直接整批读取。

### 第二层：Claude 主证据包

在本研究目录新增：

`CLAUDE_EVIDENCE_PACKET.md`

这是 Claude 后续默认阅读的主文件，必须做到**离开图片也能理解 18 篇帖子实际说了什么**，但比逐张图片省很多上下文。

每篇固定结构：

```markdown
## 001 — 标题

作者 / 点赞 / 收藏 / 评论 / 搜索词

### 原帖主要观点
用 3–6 个完整自然段或紧凑要点，忠实说明帖子实际主张和方法。

### 图片补充的关键信息
只放 note.md 没覆盖、但会改变理解的内容。

### 具体做法
列出作者实际使用的步骤、工作流、提示方式、查重方式、筛选方式或工具组合。

### 失败、限制或反例
只写帖子真实出现的内容。

### 人在流程中的角色
说明作者把哪些判断留给人，哪些交给 AI。

### 来源
- note.md
- images/02.png
- images/05.png
...
```

要求：

- 每篇通常控制在 350–900 个中文字符；少数信息特别密集的长帖可到约 1200 字，简单帖子应更短。
- 18 篇总长度目标约 **1 万–1.8 万中文字符**。这是 Claude 默认消费层，优先保留会改变判断的信息；更多细节留在各帖 `image_evidence.md`。
- 忠实保留不同作者之间的冲突，不主动调和。
- 明确区分“帖子原话/原意”和“Codex 的归纳”。
- 不评价谁对谁错。
- 不把热度当成科学正确性。
- 不写 DII 的新工作流方案，不替 Claude 做最终架构设计。

### 第三层：Claude 快速索引

新增：

`CLAUDE_INDEX.md`

控制在约 2,000–4,000 中文字符，帮助 Claude 决定先读哪些帖子。

先给一张 18 行索引表，字段：

- 编号
- 标题
- 作者
- 点赞
- 类型标签
- 一句话主题
- 最有价值的证据
- 主要来源图片

类型标签只从以下集合选择，可多选：

- 候选生成
- 文献驱动
- research gap
- 查重 / 前作核验
- 候选筛选
- 审稿人 / 反方
- 上下文积累
- 人机分工
- 失败 / 负结果
- 自动科研系统
- Skill / Agent 工作流

表后再给一个**机械式主题导航**，例如：

- 想看“为什么 AI 想不出好 idea” → 002、007、013、018
- 想看“如何从真实文献出发” → ...
- 想看“如何做 novelty check” → ...
- 想看“Auto Research 失败边界” → ...

这里只做导航，不做最终研究结论。

## 四、图片读取方式

优先直接使用你当前可用的多模态/图片理解能力读取本地 PNG。

如当前环境不能直接读取某张图，可以使用本机已有能力做最轻量的辅助；不要安装新的重型 OCR 套件，不要重新打开小红书 App，也不要重新采集。

对图片中的文字：

- 重要研究步骤、提示词、判断标准、失败描述：尽量忠实转写；
- 重复正文：不重复；
- 装饰文字和 UI：忽略；
- 结构图：转成层级关系或流程；
- 表格：转成 Markdown 表格或紧凑列表；
- 看不清：标记无法确认。
