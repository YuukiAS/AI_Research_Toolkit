## 02.png

### 新增文字 / 信息
`Scientific Brainstorming` 适合“没思路”阶段：先给研究方向、当前卡点和现实限制，它不会立刻给 10 个选题，而是连续追问，再通过跨学科类比、反转假设、改变研究尺度等方式扩展视角。

示例提示：研究长期任务中的 Agent 自我更新，目前想法都围绕 memory 展开；先不要给完整方案，连续追问，再帮助打开几条新方向。作者把它比作不断追问的科研搭子。

### 图示或结构
`问题与限制 → 连续追问 → 思维转换 → 新方向`。

## 03.png

### 新增文字 / 信息
`Hypothesis Generation` 不适合凭空想题，更适合解释实验异常：围绕一个结果提出几种竞争性解释，再分别给出预测、反例和验证实验。

示例要求：模型在很短任务中加入记忆会提升表现，但任务变长后记忆越多反而越差；请给出几个机制不同的解释，并设计能区分这些解释的最小实验。作者认为最有价值的继续追问是：“看到什么结果，才能证明这个解释是错的？”

### 图示或结构
`异常结果 → 竞争假设 → 可证伪预测 → 区分性最小实验`。

## 04.png

### 新增文字 / 信息
`Brainstorming Research Ideas` 先区分研究者手里是“问题”还是“方法”：可能已发现真实问题、正在找解法，也可能已有方法、正在找应用。skill 先分清出发点，再从不同角度发散和筛选，最后把模糊兴趣收敛成具体研究问题。

示例：有一种低成本视频时序建模方法，但没找到真正值得解决的问题；要求按 solution-first 帮找应用，最后留下 3 个最值得继续查的方向。目标是从“有兴趣”走到“能提问题”。

### 图示或结构
双入口：problem-first 或 solution-first，最终都收敛为问题。

## 05.png

### 新增文字 / 信息
`Creative Thinking for Research` 用于想法全是“小修小补”的阶段，不负责整理完整项目，而是强制换框架：类比其他领域、反转默认假设、重定义目标、改变约束。

示例：现有方案只是在短期记忆上再加一个模块，已陷入惯性增量；要求分别用问题重构、跨领域类比和约束反转重想三遍。图片用“怎样让这一步计算更快”与“这一步能不能直接消失”对比局部优化和问题重构。

### 图示或结构
通过三种强制变换摆脱渐进式局部改动。

## 06.png

### 新增文字 / 信息
`Research Gap Finder` 强调先把文献对齐，不急着制造 gap。“研究很少关注”可能只是检索不足。skill 先梳理已有研究、瓶颈和争议，再判断发现的是研究空白、工程机会、评测不足，还是单纯文献没搜全。

示例：给出自己精读的 12 篇论文，判断长期 Agent 记忆通过离线摘要修改是否是真实缺口，并指出还缺哪些文献。作者认为其用途不是急着证明创新，而是检验 gap。

### 图示或结构
`现有文献对齐 → 缺口类型判定 → 缺失检索清单`。

## 07.png

### 新增文字 / 信息
`Idea Creator` 先铺开一批方向，再决定先做哪个。给明确大方向后，它生成多组候选，并按新颖性、可行性、影响力和实验成本等维度筛选排序；结果应是一份带优先级的候选清单，而不是一个标题。

示例约束：围绕“长任务中的自进化 Agent”生成候选；条件是单卡、两周、不能重新训练大模型；先查相关工作，再按新颖性和最小验证成本排序。作者称它真正省时间之处是先筛掉根本做不了的方向。

### 图示或结构
`约束内批量生成 → 多维排序 → 带优先级候选`。

## 08.png

### 新增文字 / 信息
`Idea Discovery` 更像科研前期流水线，不只是脑暴：`文献调研 → 生成 idea → 查新 → 模拟评审 → 修改方案 → 实验计划`。产物除候选方向外，还包含完整 proposal 和后续实验安排。

示例：围绕长期运行的自进化 Agent 做 idea discovery；参考一篇核心论文；预算单卡 24G，周期 14 天；优先考虑能快速验证的方向。适合让 AI 继续往前推，而非只想一下。

### 图示或结构
从候选生成延伸到评审、修订和可执行实验计划。

## 09.png

### 新增文字 / 信息
`IdeaSpark` 的目标是最终交付一个像样的 idea，不追求一次生成几十个方向。它先读文献、定位瓶颈，再选择合适构思模式，生成候选；随后检查相关工作、审计逻辑，最终整理成完整 Idea Card。

示例：研究长期运行 Agent 如何更新策略，但不希望依赖不断扩大 memory；要求判断更适合用哪种构思模式，再给一个可实现、可证伪的方案。最终通常包括 `Title / Motivation / Method / 证据链 / 验证计划`。作者概括为：不是帮忙多想几个，而是把一个方向尽量磨完整。

### 图示或结构
`瓶颈识别 → 构思模式选择 → 候选 → 前作/逻辑审计 → Idea Card`。
